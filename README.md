# RoboMaster 视觉仿真实践指南

面向 RoboMaster 视觉与机器人仿真的非官方实践指南，按比赛时间线覆盖 Windows WSL 安装 ROS 2 Humble、导航仿真、离线视觉、算法在环与渲染感知的实施步骤、赛前彩排、正式演示验收和赛后复盘方法。

**从 [操作指南](GUIDE.md) 开始。**

## 本仓库包含什么

- Windows + WSL2 安装 Ubuntu 22.04 与 ROS 2 Humble 的流程（命令转录自官方文档）。
- 按比赛过程组织的完整流程：环境准备 → 资产核查 → 分链调试 → 赛前彩排 → 正式演示 → 赛后复盘。
- 可迁移的方案选择、环境核查、验收与排障方法。
- 一次基于 ROS 2 Humble、Nav2、OpenVINO 和 Bevy 的历史实验经验，以及适用范围。
- 对不同输入、评分方法和未完成部分的清晰说明。

## 不包含什么

本仓库仅发布原创指导文档，**不包含**第三方源码、补丁、模型权重、视频、离线依赖包、现场脚本或二进制文件；也不是一键安装包。文中提及的上游需自行从原项目获取，配置、脚本和模型须根据环境自行准备并遵守各自许可。历史现场使用过的专用桥接和刷分程序未随本仓库发布，因此仅凭本仓库不能直接复现其全部结果。

| 路线 | 输入 | 可以验证 | 不能据此证明 |
|---|---|---|---|
| 导航 | 地图与目标 | Nav2 运动闭环 | 视觉识别或射击 |
| 视觉 demo | 离线视频 | 检测与后续算法处理 | 来自模拟器的实时感知 |
| 算法回归 | 理想角点 | 解算、跟踪与预测的相对变化 | 检测召回或真实命中 |
| 渲染感知 | 实时图像 | 检测到控制的实验链 | 仅凭画面或 topic 连通证明完整闭环 |

历史实验中，Bevy 图像及控制接口接入不等于稳定锁定、遮挡恢复和碰撞计分已通过验收；该链路仍需继续验证。本项目不是 RoboMaster 官方作品，也与下列上游项目无官方隶属关系。
